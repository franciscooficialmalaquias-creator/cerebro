# Cérebro

O app de notas do Malaquias, publicado aqui pelo GitHub Pages.

Este repositório tem só o app. As notas ficam num repositório privado e só chegam
ao app com o token de cada aparelho (guardado no próprio aparelho).

O código-fonte e a história ficam no repositório privado cerebro-app; não edite aqui,
rode `node scripts/publicar.mjs` lá.
